BANGLADESH DIASPORA BALLERS — GITHUB PAGES EDITION

WHAT THIS IS
A static HTML/CSS/JavaScript version designed to publish on GitHub Pages.
It is not the PHP + MySQL application. GitHub Pages cannot run PHP or MySQL.

PUBLISH ON GITHUB
1. Download and extract BDB_GitHub_Pages.zip on your device.
2. Open your GitHub repository (for example, bdb-platform).
3. Choose Add file > Upload files.
4. Upload the CONTENTS of the extracted BDB_GitHub_Pages folder:
   - index.html
   - assets/ folder
   - README.txt
   Do not upload the ZIP as the only file.
5. Commit the changes to the main branch.
6. Open repository Settings > Pages.
7. Under Build and deployment choose "Deploy from a branch".
8. Select Branch: main and Folder: / (root), then Save.
9. Wait for deployment and open the URL shown in Settings > Pages.

FEATURES
- Responsive black-themed BDB landing page
- Player showcase with search and filters
- English/Bengali text toggle
- Player submission form that opens the visitor's email app
- Contact email link

IMPORTANT LIMITATIONS
- The sample player cards are static demonstration content. Confirm you have permission to publish any player's details and image.
- The submission form does NOT save entries to a database. It opens an email draft.
- No user accounts, login, scout dashboard, admin panel, database, photo upload or profile approval workflow are included.
- To add or edit public player cards, edit index.html and commit the changes.
- Do not publish minors' private contact details, exact date of birth, documents or sensitive information.
